# 5
d = {1: "a", 1.0: "b", True: "c"}
print(d, len(d))

==>> output = {1: 'c'} 1
The keys 1, 1.0, and True compare equal and have the same hash, so they represent one dictionary key. Each assignment replaces the value; the last value is 'c'.

# 7
d = {"a": 1, "b": 2}
print(d.pop("z", None), d.popitem())

==>> output = None ('b', 2)
pop("z", None) returns the default None because "z" is not in the dictionary. 
popitem() removes and returns the last inserted pair, ("b", 2).

# 8
print({v: k for k, v in {"a": 1, "b": 1}.items()})

==>> output ={1: 'a', 1: 'b'}

Reason: This is a dictionary comprehension that swaps each key and value. Both original values are 1, so they become the same key in the new dictionary. Dictionary keys must be unique, so the later value 'b' replaces 'a'. The actual output is {1: 'b'}.
